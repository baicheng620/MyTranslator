# 全能网页翻译器 Pro

一款 Chrome 浏览器扩展，支持一键翻译整个网页内容，多翻译 API 自动切换，稳定可靠。

## 功能

- 一键翻译当前网页全文
- 支持自动检测原文语言
- 支持中文、英语、日语、韩语、法语互译
- 多 API 备选（Google Translate → MyMemory），自动切换
- 一键恢复原文

## 安装

1. 下载或克隆本仓库
2. 打开 Chrome，进入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本项目文件夹

## 使用

1. 点击浏览器工具栏中的扩展图标
2. 选择原文语言和目标语言
3. 点击「一键翻译全文」
4. 如需恢复，点击「恢复原文」

## 技术栈

- Chrome Extension Manifest V3
- Google Translate API（非官方）
- MyMemory Translation API（备选）
